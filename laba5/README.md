# Лабораторна робота №5. Асинхронні дані та GAS API

Світлофор із ЛР4 завантажує запис `main` із Google Sheets і відновлює збережений сигнал. Таймер, орієнтація та ручні лічильники працюють у контексті React. Google Sheets оновлюється після натискання «Зберегти поточний сигнал».

## Google Sheets і Apps Script

1. Створіть окрему таблицю з аркушем `TRAFFIC_LIGHTS`. Запишіть `id` і `current_signal` у A1 і B1, а `main` і `red` у A2 і B2.
2. Відкрийте «Розширення → Apps Script» та вставте в редактор вміст `gas/Code.gs`.
3. У налаштуваннях проєкту додайте Script Property `DB_SPREADSHEET_ID` зі значенням ідентифікатора таблиці між `/d/` та `/edit` в її URL.
4. Створіть розгортання типу Web app від імені власника. Оберіть доступ «Усі», якщо це дозволено політикою акаунта. Скопіюйте версійний URL із суфіксом `/exec`. Усі, хто має цей URL, зможуть читати та змінювати навчальні сигнали.

## Запуск клієнта

Клієнт уже налаштований на опублікований GAS. Для власного розгортання скопіюйте `.env.example` у `.env.local` та задайте свій `VITE_GAS_API_URL`. Команди виконуйте в каталозі `laba5`.

```sh
npm ci
npm run dev
```

Для перевірки збірки виконайте `npm run lint` і `npm run build`.

## Перевірка

- Відкрийте `/traffic-light`. Перевірте, що після завантаження показано сигнал із рядка `main`. Під час тесту можна вимкнути мережу, перезавантажити сторінку, відновити мережу й натиснути «Повторити».
- Оберіть інший сигнал, натисніть «Зберегти поточний сигнал» і дочекайтеся підтвердження. Перевірте клітинку B2 та перезавантажте сторінку.
- Запустіть автоматичний цикл. У Network немає нових POST-запитів, доки кнопку збереження не натиснуто. Під час навігації на «Статистику» та назад локальний стан зберігається.
- Для жовтого сигналу після завантаження відновлюється перша жовта фаза, за якою йде зелена.

## Контракт API

`GET /exec?action=list` повертає `data.trafficLights`. `POST /exec` із типом `text/plain;charset=utf-8` приймає JSON `{"action":"updateState","id":"main","currentSignal":"green"}` і повертає `data.trafficLight`. Обидві відповіді мають поля `ok`, `data` та `error`. Клієнт звертається до GAS через `src/api/trafficLightsApi.js`, а GAS читає та оновлює Google Sheets.
