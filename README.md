# Frontend Labs

Лабораторні роботи з Frontend-розробки.

## Лабораторна робота №1

**Тема:** Налаштування робочого середовища

Створено базовий React-проєкт за допомогою Vite.

Проєкт знаходиться у папці `laba1`.

## Лабораторна робота №2

**Тема:** Початок роботи з React

Реалізовано React-компоненти `Light` та `TrafficLights`. Продемонстровано горизонтальний та вертикальний варіанти світлофора.

Проєкт знаходиться у папці `laba2`.

## Лабораторна робота №3

**Тема:** Поведінка в часі, ефекти та анімація

Реалізовано ручний та автоматичний режими світлофора, статистику натискань і зміну орієнтації. Таймер керується через `useEffect` із коректним очищенням, а зміни сигналів супроводжуються CSS-переходами.

Проєкт знаходиться у папці `laba3`.

## Лабораторна робота №4

**Тема:** Маршрутизація та спільний стан застосунку

Додано SPA-маршрутизацію через React Router, спільний макет і сторінки світлофора, статистики та огляду стану. `TrafficLightsProvider` зберігає спільний стан і роботу таймера під час переходів між сторінками.

Проєкт знаходиться у папці `laba4`.

## Запуск

Перейти до папки потрібної лабораторної роботи, наприклад:

```bash
cd laba4
```

Для інших робіт використати `laba1`, `laba2` або `laba3`.

Встановити залежності та запустити проєкт:

```bash
npm ci
npm run dev
```

Для ЛР3 і ЛР4 використовуйте Node.js 24 (`nvm use 24`).
